# SimpleVerse (Paper 1.21.4, Java 21)
Bauen: `mvn package` -> target/SimpleVerse.jar in plugins/ legen.

Erster Start: Als Konsole `mv op <dein name> <lobby-welt>` und in der Lobby `/setlobby`.
Befehle: /mv create|import|delete|load|unload|list|info|state|meta|setspawn|spawn|tp|op|deop|setlobby|portal|reload
/tp <welt> (Tab-Completion), /mvtp, /lobby, /setlobby
Meta: alias, mode (spawn|last), gamemode, pvp, difficulty, nether, end, autoload
